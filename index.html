板塊輪動

獲利了結、保留淨利幣、把利潤滾到落後標的。報價來自 CoinMarketCap，CoinGecko 備援。

連線設定

金鑰兩種放法擇一：填在這裡，會以明文存在這台裝置的瀏覽器，隨請求送到你的 Worker（共用電腦請用完按「連線設定」清掉）；或存成 Worker Secret（見下方步驟），這兩格留空，換裝置也不用再填。

Worker 設定步驟與程式碼
  1. Cloudflare 後台 → Workers & Pages → 你的 Worker → Edit code，把下方程式碼整段貼上，並把 ALLOW 改成你的 GitHub Pages 網域（只要 https://帳號.github.io，不含路徑）。
  2. 回到 Worker → Settings → Variables and Secrets → Add，類型選 Secret：名稱 CMC_KEY 填 CoinMarketCap 金鑰；再新增 CG_KEY 填 CoinGecko 金鑰。
  3. 按 Deploy。之後網頁只要填 Worker 網址就能用，換電腦也一樣。
// 金鑰優先用 Worker 的 Secret：CMC_KEY、CG_KEY（Settings → Variables and Secrets）；沒設就用網頁送來的金鑰
const ALLOW = ["https://你的帳號.github.io"]; // 改成你的 GitHub Pages 網域（不含路徑）
const ROUTES = {
  "/v2/cryptocurrency/quotes/latest": (env, h) => ["https://pro-api.coinmarketcap.com/v2/cryptocurrency/quotes/latest", { "X-CMC_PRO_API_KEY": env.CMC_KEY || h.get("X-CMC_PRO_API_KEY") || "" }],
  "/cg/coins/markets": (env, h) => ["https://api.coingecko.com/api/v3/coins/markets", { "x-cg-demo-api-key": env.CG_KEY || h.get("x-cg-demo-api-key") || "" }]
};
export default {
  async fetch(req, env) {
    const o = req.headers.get("Origin") || "";
    const cors = { "Access-Control-Allow-Origin": ALLOW.includes(o) ? o : ALLOW[0], "Access-Control-Allow-Methods": "GET, OPTIONS", "Access-Control-Allow-Headers": "X-CMC_PRO_API_KEY, x-cg-demo-api-key", "Vary": "Origin" };
    if (req.method === "OPTIONS") return new Response(null, { headers: cors });
    if (req.method !== "GET" || !ALLOW.includes(o)) return new Response("forbidden", { status: 403, headers: cors });
    const u = new URL(req.url), route = ROUTES[u.pathname];
    if (!route) return new Response("not allowed", { status: 404, headers: cors });
    const [target, auth] = route(env, req.headers);
    const r = await fetch(target + u.search, { headers: { ...auth, "Accept": "application/json" } });
    return new Response(r.body, { status: r.status, headers: { ...cors, "Content-Type": "application/json" } });
  }
};

策略參數

小幣估值追到龍頭這個比例，就算過熱

幣跟整份名單比；群組跟各群組中位比

不管別人漲多少，超過就算過熱

24H 量 ÷ 市值，低於即觀望

量太小容易被滑價吃掉

群組與龍頭

龍頭用來比 FDV（小幣估值追到龍頭的幾 %）。龍頭可以不在名單裡（例如 BNB、TON、TAO 會自動抓報價）；留空則該群組不比 FDV。

觀察名單

群組決定輪動比較的板塊，標籤用來篩選（多個用逗號分隔）。CMC ID 用來精準查價、避免同代號撞名；新增的幣留空會改用代號查。數量、成本價、目標倉位選填。

文字匯入 / 匯出

支援 CSV 或 JSON。CSV 欄位順序：代號,群組,龍頭,數量,成本價,淨利幣,目標倉位,標籤,CMC ID,CoinGecko ID,名稱（只有代號必填，可含標題列；標籤之間用 | 分隔）。JSON 匯出是完整備份（名單、群組、參數、利潤池與交易紀錄），用「取代名單」匯入即可還原。

名單、持倉、利潤池與交易紀錄都會刪除，建議先匯出 JSON 備份

此工具提供的是規則化的提示，不是投資建議。群組量能來自 CoinMarketCap 的 24H 成交量變化（CoinGecko 補上的幣沒有這項，不計入）；換手率基準來自你的觀察名單。
